# 小说阅读器

一个简洁、流畅的在线小说阅读器，支持多本小说管理和个性化阅读设置。

## ✨ 特性

- 📚 **多本小说管理** - 支持添加和管理多本小说
- 🔍 **快速搜索** - 按书名、作者或描述搜索小说
- 📖 **舒适阅读** - 支持多种主题（浅色/护眼/深色）、字体大小和行间距调节
- 📑 **目录导航** - 快速跳转到任意章节
- 💾 **自动保存** - 阅读进度自动保存，刷新不丢失
- ⌨️ **键盘快捷键** - 支持左右方向键切换章节
- 📱 **响应式设计** - 完美支持手机、平板和桌面设备
- 🌙 **夜间模式** - 护眼深色主题，保护视力

## 🚀 快速开始

### 方法一：本地运行

#### Windows 用户
直接双击 `启动网站.bat` 文件即可启动。

#### 手动启动
```bash
# 使用 Python 启动本地服务器
python -m http.server 8000

# 或使用 Node.js
npx serve
```

然后在浏览器中访问 `http://localhost:8000`

### 方法二：部署到 GitHub Pages

详细的部署步骤请参考 [部署到GitHub Pages指南.md](部署到GitHub Pages指南.md)

## 📖 使用说明

### 添加小说

#### Windows 用户
双击 `自动添加小说.bat` 文件即可自动添加小说。

#### 手动添加

1. 将小说文本文件放入 `novel/` 目录
2. 运行转换脚本：
   ```bash
   python convert_novels.py
   ```
3. 刷新页面即可看到新添加的小说

### 阅读设置

- **主题切换**：点击设置按钮，选择浅色、护眼或深色主题
- **字体大小**：调整字体大小（14px - 24px）
- **行间距**：选择紧凑、适中或宽松的行间距

### 快捷键

- `←` 左箭头：上一章
- `→` 右箭头：下一章
- `Esc`：关闭设置面板或目录

## 📁 项目结构

```
Novelreader/
├── index.html              # 主页 - 小说列表
├── reader.html             # 阅读器页面
├── app.js                  # 应用逻辑
├── styles.css              # 样式文件
├── novels.json             # 小说元数据
├── data/                   # 小说数据目录
│   ├── novel_0.json
│   ├── novel_1.json
│   ├── novel_2.json
│   └── novel_3.json
├── novel/                  # 原始小说文本目录
├── auto_add_novels.py      # 自动添加小说脚本
├── convert_novels.py       # 小说转换脚本
├── 启动网站.bat            # Windows 启动脚本
├── 自动添加小说.bat        # Windows 添加小说脚本
└── 部署到GitHub Pages指南.md
```

## 🛠️ 技术栈

- **前端框架**：纯 HTML + JavaScript
- **UI 框架**：Bootstrap 5
- **数据存储**：LocalStorage（阅读进度）
- **脚本语言**：Python 3.x（小说处理）
